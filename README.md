FastTLS 的组织首页与公共协作模板。

- [中文组织首页](profile/README.md)
- [English organization profile](profile/README_EN.md)
- [贡献指南 / Contribution guide](CONTRIBUTING.md)
- [问题模板](.github/ISSUE_TEMPLATE/)
- [Pull Request 模板](.github/PULL_REQUEST_TEMPLATE.md)

GitHub 使用 `profile/README.md` 展示公开组织首页。中英文首页应同步更新；新增项目入口前，请核实仓库地址、职责与发布状态。

此仓库的贡献指南、Issue 和 PR 模板作为组织默认内容，为未自行配置相应文件的仓库提供指引。仓库自身的配置优先；Issue 模板的继承规则见 [GitHub 文档](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)。

修改时检查相对链接和 GitHub 分支路径，不将本地文件路径、未发布 API 的安装承诺、未经证实的浏览器一致性或许可证声明写入首页。

This repository contains the public FastTLS organization profile and shared contribution templates. Keep both profile languages aligned and verify repository links, responsibilities, and release status when updating them.
